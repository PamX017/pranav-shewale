# Portfolio (Next.js + Tailwind)

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Edit your content

All text lives in `lib/data.ts`. Replace the placeholder links first:

- `profile.github` and `profile.linkedin`
- each project's `href` in `projects`

## Deploy

Push to GitHub and import the repo on https://vercel.com. No configuration needed.
